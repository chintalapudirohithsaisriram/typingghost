# Architecture

TypingGhost is a React and TypeScript application built with TanStack Start, TanStack Router, Vite, and Bun. Its source layout follows TanStack's file-based routing conventions and separates route pages, shared interface components, reusable hooks, and domain logic.

## Source map

| Location | Responsibility |
| --- | --- |
| `src/routes/` | URL pages, route-level metadata, redirects, and page composition. |
| `src/components/` | TypingGhost-specific interface pieces shared across pages. |
| `src/components/ui/` | Reusable visual controls and layout primitives. |
| `src/hooks/` | React state and browser interaction, including typing sessions and profile hydration. |
| `src/lib/typing.ts` | Typing statistics and input-related domain logic. |
| `src/lib/typing-content.ts` | Course lessons, keyboard rows, finger mappings, and original practice text. |
| `src/lib/profile.ts` | Progress types, validation, migration, aggregation, and coaching suggestions. |
| `src/lib/settings.ts` | User preferences and their application to the interface. |
| `src/lib/storage.ts` | The single browser-storage boundary. |
| `src/styles.css` | Global styles and shared design tokens. |
| `src/router.tsx`, `src/start.ts`, `src/server.ts` | Router, application start, and server setup. |
| `src/routeTree.gen.ts` | Generated TanStack route tree. Do not edit this file by hand. |

The routing conventions are also listed in [the route notes](../src/routes/README.md).

## Progress data flow

1. A route renders a session mode and the shared `TypingSurface`.
2. `useTypingSession` manages the active typing interaction and session measurements.
3. On completion, the route records a session through the profile domain helpers.
4. `useProfile` loads and saves the normalized profile through `src/lib/storage.ts`.
5. Home and Progress derive their displays from that saved profile.

Profile and settings data live in browser local storage. Load, import, and migration paths normalize values because local data is user-editable. The app must never treat these client-side values as proof for a protected outcome.

## Engineering safeguards

- Physical/mobile typing is handled by `TypingSurface`; passive keyboard and hand guidance must never dispatch input.
- Interactive tap-keyboard keys are real, labeled controls.
- Key positions and finger guidance must use the shared layout and mapping in the typing-content domain.
- Generated route output belongs to TanStack; change route source files and allow the toolchain to regenerate the tree.
- Preserve published Git history. The `main` branch syncs with Lovable; use a focused branch and keep `main` usable.
